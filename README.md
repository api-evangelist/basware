Basware is a cloud-based e-invoicing and purchase-to-pay platform that enables global enterprises to automate their invoice and procurement processes. The platform provides REST APIs for submitting and receiving electronic invoices across 70+ formats, managing purchase orders, and processing accounts payable workflows. Basware Network connects buyers and suppliers worldwide through a single integration point, handling format conversion and delivery. The APIs support master data management, user administration, document archiving, and real-time transaction data access for finance and procurement operations.

**Areas:** E-Invoicing · Purchase-To-Pay · Accounts Payable · Procurement · Finance Automation · B2B Payments · Invoicing

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Basware: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
